UX · Color Theme Study · 5 Variations

Meridian Run — Neon-vector palette options

Five distinct emotional registers for a fixed-screen roguelite shooter (Galaga-lineage 1-axis chassis, vertical fire-columns). Each panel lists lift-ready tokens with concrete hex values and one realistic UI snippet. Identity cue: the player reads as rescuer, never aggressor — capture/tractor columns tint as hazard, never as weapons.

Wave-modifier glyphs SWARM — scattered cluster GAUNTLET — vertical columns BOUNTY — single diamond

Accessibility (indie-serious): color is never the sole signal. The three wave-modifier types are differentiated first by shape/glyph (cluster · columns · diamond), then reinforced by hue — so they remain distinguishable in grayscale and under deuteranopia, protanopia, and tritanopia. The same glyph set is reused in every variation; only the hue mapping changes. No palette relies on a red/green-only encoding for any binary choice.
